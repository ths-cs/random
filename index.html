    My word lists

    Add your own characters, actions, settings, and twists. They mix in with the built-in ones unless you check “use only mine.” Your words are saved in this browser, so use the same computer and Chrome account to see them next time.

    Characters

    One per line. Start each with “a” or “an,” like “a sleepy sloth.” Simple shapes are easiest to animate.

    Actions

    Each action needs a technique and a principle so the plan and storyboard fill in correctly.

    Settings

    One per line. Write it so it finishes the sentence, like “in the art room” or “on a lily pad.”

    Twists

    One per line. These only appear at the Challenge level. Write them so they follow “Twist:”, like “it’s being chased.”
